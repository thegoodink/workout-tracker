☁ Google Drive sync

Sync your workout data to Google Drive so it's available on any device — desktop, iPhone, anywhere. Each device reads from and writes to the same file in your Drive.

Paste your Google Drive API key and the file ID of your sync file below. The app will read on load and write on every save.
Sync file ID (from Drive URL or created automatically)
How it works: The first time you connect, a file called workoutlog-sync.json is created in your Drive. Copy the file ID shown and paste it into this box on your other devices. From then on, hitting Sync (or saving a workout) automatically pushes your data up. Opening the app on another device pulls the latest data down.

Program start date

Set the date Week 1 begins. All week numbers, progressions, and schedules recalculate from this date.

Restart program

Resets the start date to today and clears all logged workout data. All history will be deleted. Export a backup first.

Backup & restore

Export your data to keep a safe copy, or restore from a previous backup.

Paste a previously downloaded backup below to restore. This will replace all current data.

Danger zone

Permanently delete all workout data. Cannot be undone. Export a backup first.
